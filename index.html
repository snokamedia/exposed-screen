How detection works

Everything on this page is measured live in your browser. No user-agent string is read, stored, or sent anywhere. The guesses below come purely from screen and window geometry that any website can see.

  • The diagram. The white box is your page viewport, the blue band around it is the browser's own interface (address bar, toolbars, scrollbars), the green area is the space your operating system makes available to windows, and the orange edge is the strip the OS keeps for itself: the taskbar or dock.
  • Which display. When this window sits on a secondary monitor, the browser reports the available area shifted away from the origin. The size and direction of that shift tells us whether you are on the primary display or an extended one to the left, right, above, or below it.
  • Which OS. The gap between the full screen height and the available height equals the pixels reserved for the taskbar, dock, or menu bar. Each operating system reserves a characteristic amount. A default Windows taskbar takes about 40 pixels, for example, so we match the measured gap against signatures recorded from real systems. If nothing matches, we say so instead of guessing.
  • Virtual machines. A window with zero size, a window far larger than its screen, or the classic 800×600 virtual display (along with a VM graphics driver) suggests the browser is running inside a virtual machine.

These are heuristics, not proof: resized taskbars, auto-hidden docks, display scaling, and unusual setups can all change the numbers. That is exactly the point. This is what your setup looks like to every site you visit.
